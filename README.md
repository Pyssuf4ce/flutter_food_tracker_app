## ✨ คุณสมบัติของแอป (Features)

* **Splash Screen:** หน้าจอโหลดก่อนเข้าแอปพร้อม Animation
* **Show All:** ดึงข้อมูลจาก Supabase มาแสดงเป็นรายการทั้งหมด
* **Add Record:** บันทึกเมนูอาหาร มื้ออาหาร ราคา และถ่ายรูปประกอบได้
* **Update & Delete:** แก้ไขข้อมูลเดิมหรือลบข้อมูลที่ไม่ต้องการออกได้ทันที

---

## 🛠️ เทคโนโลยีที่ใช้

* **Frontend:** Flutter (Dart)
* **Backend:** Supabase (Database & Storage)
* **Fonts:** Kanit (Google Fonts)
