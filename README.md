## ✨ Features

* 📝 **Daily Log:** บันทึกเมนูอาหารเช้า กลางวัน เย็น
* 📊 **Summary:** ดูสรุปข้อมูลโภชนาการย้อนหลัง
* 🔍 **Search:** ค้นหารายการอาหารที่เคยบันทึกไว้
* 🌓 **Dark/Light Mode:** รองรับการปรับโหมดมืดและสว่าง

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Framework:** [Flutter](https://flutter.dev)
* **Language:** [Dart](https://dart.dev)
* **Backend:** [Supabase](https://supabase.com/) (หรือระบุ Database ที่คุณใช้)
* **State Management:** [Provider / Riverpod]
